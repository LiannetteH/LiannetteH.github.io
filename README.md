## Features
- Responsive design: Screen settings for phones, tablets, and desktops
- Interactive elements: Hover effects, dark mode toggle that saves the visitor's preference, contact form
- Accessibility features: Local storage, session storage, and table generated by JavaScript
- Messages: welcome modal that appears when the page loads, and for loading message followed by confirmation

## Technologies Used
Technologies and tools used to build this website:
- HTML5: used for the website's structure and content
- CSS3: used to style the website (such as pink and purple theme or the dark mode)
- JavaScript: used to create interactive features and display project information
- GitHub: used to store project files and track changes
